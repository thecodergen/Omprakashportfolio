# Om Prakash Sethy — Haute Couture Developer Portfolio

> **Software Developer | Full-Stack Developer | AI/ML Enthusiast | Tech Entrepreneur**  
> *Designing Purpose • Building Legacy*

A high-performance personal portfolio website crafted in a dark, cinematic editorial aesthetic (Haute Couture Dark Emerald `#050806` / `#0A1410` and Brushed Champagne Gold `#B8935A` / `#D4B07A`).

---

## 🌟 Architecture & Key Features

- **Haute Couture Aesthetic**: High-contrast editorial typography (`Cormorant Garamond`, `Montserrat`, `JetBrains Mono`), delicate gold hairline dividers, velvet ambient lighting, and subtle film grain.
- **Interactive 5-Second Credential Carousel**: Auto-progressing progress bar showcasing AI/ML, Core Java OOP, Hardware & Networking, Systems, and applied credentials with pause-on-hover.
- **Dynamic Project Showcase & Architectural Modal**: Direct deep-dive modal dialogs with architecture overviews, technology stacks, and live links.
- **Complete Certificate Archive**: 19 verified technical credentials (Duke University, University of Michigan, Microsoft, TATA, Akamai, CTTC, HP LIFE, Udemy).
- **Fast & Responsive**: Mobile-first responsive grid, ambient cursor light tracking, and lightweight zero-dependency core.
- **Progressive Web App (PWA)**: Manifest and service worker caching for offline access.
